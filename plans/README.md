# Active plans

Start with [the remaining prototype plan](prototype/README.md).
Its immediate next task is [presentation exploration](prototype/EXPLORATION.md),
with [acceptance criteria](prototype/ACCEPTANCE.md) used throughout.

P1–P3 implementation plans, closeouts, trial instructions and execution journals
are historical. Their old paths contain short redirects so existing evidence and
contract links remain usable. They are not competing active plans. Use
[current state](../docs/current/STATE.md) for the implemented baseline and
[history](../docs/history/README.md) to answer a specific historical question.

Keep one active sequence and one current status per workstream. Put source-backed
task details beside the relevant milestone only when it is ready to execute.
Record results in dated evidence and link them; do not paste full execution logs
into the planning entry point. Preserve superseded plans before replacing them.
