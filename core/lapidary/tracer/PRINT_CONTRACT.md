# Display and linear-data contract

`GemTracer.read_xyz()` and `read_linear_master()` expose coverage-associated CIE 1931 2-degree XYZ. These are linear data, not viewable sRGB images. Values above one are retained. A reference master means an unfiltered estimate of the selected supported transport model; it does not add missing physics.

`GemPrint.View.DISPLAY_PREVIEW` is an exposure-adjusted display preview: rig white balance to D65, signed linear sRGB, a maximum-channel Reinhard scale, gamut mapping, and sRGB encoding. It is tone mapped and must never be called raw or used as a linear radiometric measurement. `HOUSE_PRINT` adds the explicitly authored highlight desaturation, maximum-channel extended Reinhard/contrast, soft chroma ceiling and black floor. The floor is applied after gamut mapping. Preview does not apply game styling. Job admission rejects that combination.

Neither view clips negative RGB before gamut mapping. Oklab uses signed cube roots. Out-of-gamut colors reduce chroma at constant Oklab lightness and hue to the sRGB boundary with 20 bisection steps; in-gamut colors pass through unchanged. Lightness outside [0,1] becomes black/white. Final RGB clamping absorbs numerical boundary error. This is an explicit display policy, not a claim that perceptual hue is perfectly constant for every observer or that narrowband spectral colors fit sRGB. House highlight desaturation and its optional black floor can intentionally change chromaticity.

References: [Oklab matrices and signed cube roots](https://bottosson.github.io/posts/oklab/), [constant-lightness chroma reduction](https://bottosson.github.io/posts/gamutclipping/). The project uses a bounded numerical search, not the latter article's analytic cusp solver.

One implementation serves interactive draws and offline retained-master reprints: `GemPrintPass` dispatches `gem_print.glsl`. There is no separate CPU print or compatibility transform. `GemFrameJob.display_view` participates in display identity only; print resource and shader/dispatch sources are classified as print dependencies. Changing view/print does not change an optical master key. Structural host/schema changes remain conservatively invalidating; older pre-refactor masters are historical evidence, not silently relabeled as compatible.

Linear associated XYZ is area-resolved before unassociation and all nonlinear operations. Output is sRGB8 straight alpha, with zero RGB at zero coverage. The shader never mutates its input master. Print version 4 replaces version 3. Reprint retained compatible masters after a print change; do not retrace them.

Validation: `print_gpu_check.gd` uses all 401 tabulated spectral samples plus a six-decade neutral ramp, three nonzero coverages and transparent pixels. It tests compressed-master/live byte equivalence, untouched XYZ and factory view-only master reuse. `check_print_color.py` independently checks Oklab hue/lightness from the emitted spectral inputs, neutral monotonicity and alpha. Bounds (3 degrees hue, 0.004 Oklab L) account for 8-bit quantization on the tested chromaticity/lightness domain, not universal visual acceptance. The former early RGB clamp fails this corpus by more than 43 degrees. Source dependency tests independently mutate print shader and dispatch identities.
